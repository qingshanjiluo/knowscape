# 知境 · 智能深度阅读工具 · 最终完整方案

## 一、项目概述

**知境（KnowScape）** 是一款AI驱动的深度阅读与知识蒸馏工具，帮助用户将书籍、文献、长文等复杂内容快速拆解、精炼、结构化，并通过交互式对话和可视化图谱实现高效学习。支持本地桌面应用与云端服务双模式部署，覆盖个人学习与团队协作场景。

## 二、目标用户

- **研究人员 / 学者**：需要快速消化大量论文和专著
- **终身学习者**：希望在有限时间内吸收更多书籍精华
- **知识工作者**：需要将书籍内容转化为可复用的知识资产
- **团队/组织**：需要共享知识库，统一认知

### 3.1 阶段一：导入与准备
- 支持格式：EPUB、PDF、MOBI、AZW、LaTeX、Markdown、Word、网页URL
- **内置转格式**：统一输出为Markdown格式，便于后续处理
- 扫描版PDF自动调用OCR引擎（Tesseract）进行文字识别
- 转格式失败时，支持用户手动上传纯文本/Markdown文件作为回退方案

### 3.2 阶段二：拆解与蒸馏

#### Step 1: 智能分章
- 解析文档目录结构（`<h1>/<h2>` 标签、Markdown标题、PDF书签等）
- AI语义辅助修正：识别“第一章”、“引言”、“参考文献”等关键边界
- 生成独立的章节文件，格式根据AI阅读便捷性自动选择（Markdown优先）

#### Step 2: 章节蒸馏（AI Agent体系）
- **蒸馏Agent**：读取每个章节文件，提取核心论点（每章3-5条）
- **多深度支持**：用户可配置浅/中/深三种蒸馏深度，生成对应层级的文档
  - 浅度：仅提取核心论点
  - 中度：论点 + 支撑论据/案例
  - 深度：论点 + 论据 + 关键引文

#### Step 3: 框架整理（统一Agent）
- 汇总所有章节蒸馏结果
- 识别内容类型，分类归入以下维度：
  - **方法**（Methodology）
  - **原则**（Principles）
  - **策略**（Strategies）
  - **模型**（Models）
  - **案例**（Case Studies）
  - **数据/证据**（Data/Evidence）
  - **观点/立场**（Perspectives）
- 生成全书逻辑框架（树形结构）

#### Step 4: 蒸馏文件夹生成
```
📁 书籍蒸馏文件夹
├── 📄 全书概览.md          # 一句话总结 + 核心思想 + 作者意图
├── 📄 全书框架.md          # 逻辑结构树（章-节-核心论点）
├── 📄 内容类型索引.md      # 按方法/原则/策略/模型等分类汇总
├── 📁 章节蒸馏/
│   ├── 第1章_核心.md
│   ├── 第2章_核心.md
│   └── ...
├── 📁 深度文档/            # 用户按需生成
│   ├── 第1章_深度.md
│   ├── 模型汇总.md
│   └── ...
└── 📁 原文引用/
    └── 原文片段索引.md
```

### 3.3 阶段三：交互与学习

用户通过可视化前端进入学习工作台，包含以下四种核心交互模式：

#### 模式一：图谱浏览（可视化）
- **知识图谱**：展示全书概念、人物、事件之间的关联关系
- **框架树**：章节目录的层级结构，点击节点可展开/收拢
- **类型地图**：按“方法/原则/策略/模型”分类的聚合视图
- 支持拖拽、缩放、点击跳转到对应文档

#### 模式二：文档阅读（精读）
- 阅读器中可切换查看不同深度层级（概览/框架/章节蒸馏/深度文档/原文）
- 支持在蒸馏文档中点击引用，侧边栏弹出原文上下文
- 支持高亮、批注、书签
- 支持全文搜索（含原文和蒸馏内容）

#### 模式三：对话问答（探索）
- 用户可基于全书内容向AI提问（如“作者在第3章提出的核心论点是什么？”）
- AI基于蒸馏文档 + 原文片段回答，并标注引用来源
- 支持追问和跨章节综合问题

#### 模式四：深度生成（按需）
- 用户可通过对话指定想要生成的深度内容
- 例如：“帮我生成关于‘策略’类型的所有内容，汇总成一份文档”
- AI自动从蒸馏结果中提取并生成新的结构化文档

### 4.2 进度监控与展示

| 监控项 | 展示方式 |
|--------|----------|
| 当前处理阶段 | 顶部状态栏显示“转格式中 / 分章中 / 蒸馏中 / 整理中” |
| 各阶段进度 | 进度条 + 百分比 + 已完成/总数（如“已蒸馏 8/12 章”） |
| 正在处理的文件 | 侧边栏高亮当前章节 |
| 处理日志 | 底部可展开的日志面板（详细记录每一步操作） |
| 预估剩余时间 | 基于历史数据估算 |

### 4.3 阅读与文档交互

- **双栏阅读模式**：左侧显示蒸馏文档，右侧显示原文片段（可同步滚动）
- **引用跳转**：点击蒸馏文档中的引用标记（如 `[引1]`），右侧自动定位到原文
- **浮动窗口**：在原文区域选中文字，浮动工具栏弹出“查看蒸馏解释”按钮

### 4.4 对话交互

- 对话面板可固定在右侧或作为浮动窗口
- AI回答支持引用标注，点击可跳转到对应文档/原文
- 回答中包含“继续追问”建议按钮

## 五、技术架构概览

### 5.1 双模式部署

| 部署模式 | 技术方案 | 适用场景 |
|----------|----------|----------|
| **本地桌面应用** | Tauri + React（前端） + Rust（后端） | 个人学习、离线使用、数据隐私敏感 |
| **云端服务** | Node.js/Python + PostgreSQL + 向量数据库 | 团队协作、在线访问、API服务 |

### 5.2 核心组件

| 组件 | 说明 |
|------|------|
| **文档解析引擎** | 内置格式转换（EPUB/PDF/Markdown等），输出统一格式 |
| **分章与蒸馏引擎** | 多Agent协同（分章Agent、蒸馏Agent、整理Agent） |
| **知识存储** | 结构化存储（蒸馏文档）+ 向量数据库（语义检索） |
| **对话引擎** | RAG架构（检索蒸馏文档+原文片段，生成回答） |
| **前端工作台** | React + 图谱可视化库 + 阅读器组件 |

### 5.3 本地与云端的数据同步
- 支持手动导入/导出（JSON打包）
- 支持配置自动同步（需自建WebDAV或MinIO）
- 云端版支持多用户和知识共享

## 六、用户旅程

### 首次使用流程
1. 用户打开应用 → 看到空书库 + 新手引导
2. 上传一本书 → 点击“开始拆解”
3. 进度面板实时显示拆解进程
4. 拆解完成后，自动生成蒸馏文件夹
5. 用户进入“全书概览”快速了解核心内容
6. 按需进入图谱浏览、深度阅读或对话模式

### 典型学习路径
```
快速概览 → 理解全书框架 → 精读核心章节 → 针对性提问 → 深度生成专题文档
```

## 七、品牌定位

- **中文名**：知境
- **英文名**：KnowScape
- **Slogan**：*从读到懂，一步之遥。*
- **设计风格**：知识工作台风格（沉稳、专注、信息密度高）

## 八、总结

**知境** 将复杂的阅读过程拆解为“导入 → 拆解 → 交互”三个阶段，通过AI蒸馏将几百页的书籍转化为可快速浏览、可对话追问、可按需深入的知识资产。它为深度阅读者提供了一条“从厚读到薄”的加速路径。
